# 📅 Day 1 - Basics of Computing

## 💻 What is Computing?
Computing refers to the use of computers to process data and perform tasks.

It includes:
- Input (data given to computer)
- Processing (CPU executes instructions)
- Output (result)
- Storage (saving data)

👉 Example:
When you search something on Google:
- Input → Typing query
- Processing → Server processes request
- Output → Results shown on screen

---

## ⚙️ How Computing Works?

A computer works on the **IPO Cycle**:

1. Input → Keyboard, Mouse
2. Process → CPU (Brain of computer)
3. Output → Monitor
4. Storage → Hard disk / SSD

---

## 🧠 What is RAM?

RAM (Random Access Memory) is temporary memory.

- Stores data currently in use
- Fast but volatile (data lost when power off)

👉 Example:
Opening apps, browser tabs

---

## 💾 What is ROM?

ROM (Read Only Memory) is permanent memory.

- Stores important instructions
- Non-volatile (data not lost)

👉 Example:
Booting instructions of computer

---

## 🖥 What is Operating System (OS)?

An OS is system software that manages hardware and software.

👉 Examples:
- Windows
- Linux
- macOS

### Functions of OS:
- Memory management
- Process management
- File system handling
- Device control
